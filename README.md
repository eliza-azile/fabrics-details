# fabrics-details — интернет-магазин тканей

Совместный учебный проект. Интернет-магазин с авторизацией, каталогом, корзиной и новостной лентой.

## 🎯 Мой вклад в проект

**Я реализовала клиентский фронтенд и интеграцию с бэкендом:**

- **Модуль авторизации** — форма входа/регистрации, обработка токенов, защита маршрутов
- **Главная страница новостей** — загрузка и отображение новостной ленты с сервера
- **Корзина** — добавление/удаление товаров, подсчёт суммы, синхронизация с API

> Все выполненные задачи подтверждены историей коммитов.

## 🛠️ Технологии
- JavaScript (ES6)
- HTML5, CSS3
- Fetch API (интеграция с бэкендом)

## 🚀 Как запустить
1. Клонируй репозиторий:  
   `git clone https://github.com/eliza-azile/fabrics-details.git`
2. Открой `index.html` в браузере
3. Для полной работы потребуется локальный сервер (например, `npx http-server`)
